# ТИП ПЛОСКИЕ ЧЕРВИ (Platyhelminthes)

## Основные признаки плоских червей

| Признак | Характеристика |
|---------|----------------|
| **Трехслойность** | Формируются три зародышевых листка — эктодерма (ectoderma), энтодерма (entoderma) и мезодерма (mesoderma) **(ароморфоз)** |
| **Внешнее строение** | Листообразная или лентовидная, двусторонне-симметричная форма тела **(ароморфоз)** |
| **Покровы** | У свободноживущих — реснички; у паразитических — **тегумент** (tegument) |
| **Мускулатура** | Кожно-мускульный мешок: кольцевые (musculi circulares), продольные (musculi longitudinales), диагональные (musculi diagonales) мышцы |
| **Полость тела** | Отсутствует (пространство заполнено **паренхимой** — parenchyma) |
| **Пищеварительная система** | **Слепо замкнута** (рот → глотка → кишка). Непереваренные остатки удаляются через рот **(ароморфоз)** |
| **Выделительная система** | **Протонефридии** (protonephridia) **(ароморфоз)** |
| **Дыхательная система** | Газообмен через кожу; у эндопаразитов — анаэробное дыхание |
| **Кровеносная система** | Отсутствует |
| **Нервная система** | Лестничного (стволового) типа: парный мозговой ганглий + нервные стволы с кольцевыми перемычками |
| **Органы чувств** | Два глаза (ocelli), осязательные клетки; у паразитов — редуцированы |
| **Половая система** | **Гермафродиты** (hermaphroditi), внутреннее оплодотворение, развитие прямое или с метаморфозом |
| **Бесполое размножение** | Фрагментация (fragmentatio) |

### Схема выделительной системы (протонефридии)

| Цифра | Структура |
|-------|-----------|
| 1 | Главный выделительный канал |
| 2 | Разветвления канальцев |
| 3 | Звездчатые клетки |
| 4 | Мерцательное пламя (пламя свечи) |

**Механизм работы:**
1. В паренхиме находятся крупные клетки с пучками ресничек («мерцательное пламя»)
2. Тканевая жидкость поступает в клетки путем осмоса
3. Движение ресничек направляет жидкость в канальцы
4. Происходит **реабсорбция** (обратное всасывание воды, глюкозы, витаминов)
5. Канальцы открываются наружу через выделительные поры

## Класс Ресничные черви (Turbellaria)

| Признак | Характеристика |
|---------|----------------|
| **Образ жизни** | Свободноживущие (водные, почвенные) |
| **Форма тела** | Листовидная (forma foliata) |
| **Покровы** | Кожно-мускульный мешок с ресничками (cilii) |
| **Питание** | Хищники, питается мелкими животными |
| **Дыхание** | **Аэробы** (aerobi) — не эндопаразиты |
| **Органы чувств** | Два глаза (ocelli), осязательные клетки |
| **Половая система** | Гермафродиты (гонды — gonadi) |
| **Ротовое отверстие** | На брюшной стороне тела |
| **Развитие** | **Прямое** (личинок нет) |

**Представитель:** Планария (Planaria)

### Системы органов планарии

| Система | Особенности |
|---------|-------------|
| Пищеварительная | Замкнутая, слепая |
| Выделительная | Протонефридиальная (protonephridialis) |
| Нервная | Лестничная (scalariformis) |
| Мышечная | 3 слоя |
| Кровеносная | Отсутствует |
| Дыхательная | Отсутствует (через покровы) |

## Класс Сосальщики / Трематоды (Trematoda)

| Признак | Характеристика |
|---------|----------------|
| **Образ жизни** | **Эндопаразиты** (endoparasiti) внутренних органов животных |
| **Органы прикрепления** | Две присоски — **ротовая** (acetabulum orale) и **брюшная** (acetabulum ventrale) |
| **Кожно-мускульный мешок** | **Тегумент** (tegument) + мышцы |
| **Пищеварительная система** | Рот → глотка → пищевод → 2 ветви кишечника |
| **Дыхание** | **Анаэробное** (anaerobium) |
| **Органы чувств** | Слабо развиты |
| **Половая система** | Сильно развита, высокая плодовитость |
| **Жизненный цикл** | Сложный, со сменой хозяев |

**Представители:**
- Печеночный сосальщик (Fasciola hepatica)
- Кошачья двуустка (Opisthorchis felineus)

**Строение тела:**
- Ротовая присоска (acetabulum orale)
- Рот (os)
- Брюшная присоска (acetabulum ventrale)
- Кишечник (intestinum)

### Приспособления к паразитизму у сосальщиков

| Приспособление | Значение |
|----------------|----------|
| Нет ресничного эпителия (есть тегумент) | Защита от пищеварительных ферментов хозяина |
| Редукция органов чувств | Энергосбережение |
| Сильно развитая половая система | Высокая продуктивность (R-стратегия) |
| Органы прикрепления (присоски) | Удержание в теле хозяина |
| Сложный цикл с 3 личиночными стадиями | Повышение шансов на заражение |

### Жизненный цикл печеночного сосальщика (Fasciola hepatica)

| Стадия (русский) | Стадия (латынь) | Хозяин / Среда | Что происходит |
|------------------|-----------------|----------------|----------------|
| **Марита** (взрослая особь) | Marita | КРС (окончательный хозяин) | Продуцирует яйца в кишечнике |
| **Яйцо** | Ovum | Внешняя среда (с экскрементами) | Попадает в воду |
| **Мирацидий** | Miracidium | Вода | Ресничная личинца, ищет моллюска |
| **Спороциста** | Sporocysta | Моллюск (промежуточный хозяин) | Сбрасывает реснички, превращается |
| **Редия** | Redia | Моллюск | Партеногенетическое размножение |
| **Церкарий** | Cercaria | Моллюск → вода | Хвостатая личинца, выходит в воду |
| **Адолескария** | Adolescaria | Растения (прибрежная растительность) | Покоящаяся стадия (циста) |

**Цепочка заражения:**
Корова (КРС) → яйцо → вода → мирацидий → моллюск (прудовик) → спороциста → редия → церкарий → адолескария на траве → корова поедает траву → молодая марита мигрирует в печень

### Стадии развития (по номерам на схеме)

| Номер | Стадия |
|-------|--------|
| 1 | Взрослый сосальщик (марита, половозрелая особь) |
| 2 | Яйцо (ovum) |
| 3 | Личинка с ресничками — мирацидий (miracidium) |
| 4 | Спороциста (sporocysta) в теле промежуточного хозяина |
| 5 | Редия (redia) в теле промежуточного хозяина |
| 6 | Хвостатая личинка — церкарий (cercaria) |
| 7 | Циста — адолескария (adolescaria) |

## Класс Ленточные черви / Цестоды (Cestoda)

| Признак | Характеристика |
|---------|----------------|
| **Образ жизни** | **Эндопаразиты** кишечника позвоночных |
| **Форма тела** | Лентовидная (forma taeniiformis) |
| **Строение** | **Сколекс** (scolex — головка с крючьями/присосками) → **шейка** (collum — зона роста) → членики (proglottides): незрелые → зрелые |
| **Пищеварительная система** | **Отсутствует** |
| **Дыхание** | Анаэробное (anaerobium) |
| **Покровы** | Тегумент (tegument) |
| **Половая система** | Гермафродиты (hermaphroditi), самооплодотворение |
| **Плодовитость** | Высокая (зрелые членики заполнены яйцами) |

**Представители:**
- Бычий цепень (Taenia saginata)
- Свиной цепень (Taenia solium)
- Эхинококк (Echinococcus granulosus)

### Жизненный цикл бычьего цепня (Taenia saginata)

| Стадия (русский) | Стадия (латынь) | Хозяин | Локализация |
|------------------|-----------------|--------|-------------|
| Взрослая особь | Taenia saginata | Человек (окончательный хозяин) | Кишечник |
| Яйца | Ova | Почва, растения | — |
| Онкосфера (6-крючная личинка) | Oncosphere | КРС (промежуточный хозяин) | Кишечник → кровь |
| Финна (пузырьковидная личинка) | Cysticercus / Finnа | КРС | Мышцы |
| Заражение человека | — | Человек | Употребление финнозного мяса |

**Цепочка:**
Зрелые членики с яйцами → фекалии человека → почва, растения → КРС проглатывает яйца → в кишечнике онкосфера → проникает в кровь → оседает в мышцах → финна → человек ест непрожаренное мясо → в кишечнике выворачивается головка → взрослая особь

> **Заболевание человека:** финноз (cysticercosis)

### Жизненный цикл широкого лентеца (Diphyllobothrium latum)

| Стадия (русский) | Стадия (латынь) | Хозяин |
|------------------|-----------------|--------|
| Взрослая особь | Diphyllobothrium latum | Человек, хищные млекопитающие (рыбоядные) |
| Яйцо | Ovum | Вода |
| Корацидий | Coracidium | Вода |
| Проникновение | — | Циклоп (1-й промежуточный хозяин) |
| Финна | Finnа / Plerocercoid | Рыба (2-й промежуточный хозяин — мышцы) |
| Заражение человека | — | Употребление сырой/плохо прожаренной рыбы |

## Ароморфозы плоских червей (Platyhelminthes)

| № | Ароморфоз (русский) | Ароморфоз (латынь) |
|---|---------------------|---------------------|
| 1 | Появление мезодермы — третьего зародышевого листка | Mesoderma |
| 2 | Появление мочевыделительной системы | Systema excretorium |
| 3 | Появление половой системы | Systema genitale |
| 4 | Появление специализированных органов пищеварения | Organa digestiva specialisata |

| 6 | Стволовая нервная система (объединение нервных клеток в ганглии) | Systema nervosum truncalis |

# ТИП КРУГЛЫЕ ЧЕРВИ (Nemathelminthes)

## Класс Нематоды (Nematoda)

| Признак | Характеристика |
|---------|----------------|
| **Форма тела** | Веретеновидная (forma fusiformis) |
| **Кожно-мускульный мешок** | Кутикула (cuticula) + гиподерма (hypoderma) + продольные мышцы (musculi longitudinales) |
| **Полость тела** | **Первичная** (pseudocoelom) — заполнена жидкостью (гидроскелет + транспорт) |
| **Пищеварительная система** | 3 отдела, **сквозная** (есть анальное отверстие) |
| **Дыхание** | У эндопаразитов — анаэробное (anaerobium) |
| **Выделительная система** | Видоизмененные протонефридии — шейные железы (glandulae cervicales) |
| **Нервная система** | Окологлоточное нервное кольцо (circulus nervosus peripharyngealis) + 2 ствола (брюшной и спинной), лестничного типа |
| **Половая система** | **Раздельнополые** (dioeci) — есть половой диморфизм (dimorphismus sexualis) |
| **Размножение** | Только половое, внутреннее оплодотворение |
| **Регенерация** | Отсутствует |
| **Развитие** | У паразитов — с метаморфозом; у свободноживущих — прямое |

**Представители:**
- Аскарида человеческая (Ascaris lumbricoides)
- Острица (Enterobius vermicularis)

### Цикл развития аскариды (Ascaris lumbricoides) — без смены хозяина

| Этап | Где происходит |
|------|----------------|
| Заражение | Проглатывание яиц с личинкой (через немытые руки, овощи, фрукты) |
| Выход личинки из яйца | Кишечник |
| Миграция (1-2 недели) | Через стенку кишечника → кровеносные сосуды → малый и большой круг кровообращения |
| Накопление | Капилляры альвеол легких |
| Подъем | Бронхи → трахея → глотка (откашливание + заглатывание) |
| Взрослая особь | Кишечник (размножение) |

### Вред аскариды для человека (Ascaris lumbricoides)

| Последствие | Проявление |
|-------------|------------|
| Интоксикация | Продукты обмена всасываются в кровь |
| Малокровие (анемия) | Особенно у детей |
| Общее состояние | Повышенная утомляемость |
| Иммунитет | Снижение |

### Меры профилактики аскаридоза

| Группа мер | Конкретные действия |
|------------|---------------------|
| **Личная гигиена** | Чистота рук, овощей, фруктов |
| **Гигиена питания** | Кипячение воды, термическая обработка пищи |
| **Санитарные нормы** | Закрытые туалеты, мусорные ямы, защита водоемов и почвы от фекалий |
| **Борьба с переносчиками** | Уничтожение мух |

### Другие паразитические круглые черви

| Вид (русский) | Вид (латынь) | Заболевание | Особенности |
|---------------|--------------|-------------|-------------|
| **Острица** | Enterobius vermicularis | Энтеробиоз | Паразитирует в толстой кишке, ночной зуд, **аутоинвазия** (самозаражение) |
| **Ришта** | Dracunculus medinensis | Дракункулез | Вызывает подкожные нарывы, промежуточный хозяин — циклоп (Cyclops) |

### Меры профилактики дракункулеза (Dracunculus)

| Мера | Описание |
|------|----------|
| Запрет купания | В потенциально опасных водоемах |
| Уничтожение циклопов | Промежуточные хозяева |
| Заселение планктоноядных организмов | Естественные враги циклопов |
| Чистка водоемов | — |
| Кипячение воды | Перед употреблением |

# ТИП КОЛЬЧАТЫЕ ЧЕРВИ (Annelida)

## Общая характеристика типа

| Признак | Характеристика |
|---------|----------------|
| **Симметрия** | Двусторонняя (bilateralis) |
| **Трехслойность** | Triploblastica |
| **Полость тела** | **Вторичная** — **целом** (coelom), выстлан эпителием |
| **Членистость** | Тело разделено на сегменты (кольца) — **метамерия** (metameria) |
| **Кожно-мускульный мешок** | Кутикула (cuticula) + однослойный эпителий + 2 слоя мышц (продольный — musculi longitudinales и кольцевой — musculi circulares) |
| **Кровеносная система** | **Замкнутого типа** (systema circulatorium clausum) |
| **Дыхательная система** | Отсутствует (у малощетинковых — через кожу) или кожные жабры на параподиях (у многощетинковых) |
| **Выделительная система** | **Метанефридии** (metanephridia) |
| **Пищеварительная система** | Сквозная, есть зоб (ingluvies) |
| **Нервная система** | Парные спинные ганглии + брюшная нервная цепочка (ganglia ventralis) |
| **Размножение** | Половое (гермафродиты, перекрестное) + бесполое (фрагментация) |
| **Развитие** | Прямое |

## Класс Многощетинковые (Polychaeta)

| Признак | Характеристика |
|---------|----------------|
| **Щетинки** | Много на поверхности тела (setae) |
| **Параподии** (parapodia) | Мускулистые выросты тела для движения |
| **Среда обитания** | Море, свободноживущие |
| **Питание** | Хищники |
| **Дыхание** | Кожное или **жабры кожного происхождения** (branchiae) — например, у пескожила (Arenicola marina) |
| **Органы чувств** | Глаза (oculi), осязательные клетки, **статоцисты** (statocystae) — органы равновесия |
| **Размножение** | Половое + бесполое (деление, почкование) |
| **Развитие** | С личинкой **трохофорой** (trochophora) |

## Класс Малощетинковые (Oligochaeta)

| Признак | Характеристика |
|---------|----------------|
| **Щетинки** | Мало на поверхности тела (pauci setae) |
| **Половая система** | **Гермафродиты** (hermaphroditi) |
| **Оплодотворение** | Перекрестное через слизистую муфту (**поясок** — clitellum) |
| **Развитие** | **Прямое** (из кокона выходят молодые черви) |
| **Дыхание** | Через покровы (кислород из почвы) |
| **Кровеносная система** | 5 кольцевых сосудов — «сердец» |
| **Регенерация** | Способны |

**Представитель:** Дождевой червь (Lumbricus terrestris)

### Процесс размножения дождевого червя (Lumbricus terrestris)

| Этап | Описание |
|------|----------|
| 1 | Две особи обмениваются спермой через слизистую муфту (поясок — clitellum) |
| 2 | Сперма сохраняется в **семяприемнике** (receptaculum seminis) |
| 3 | Муфта сползает к переднему концу, захватывая яйцеклетки |
| 4 | Оплодотворение спермой из семяприемника |
| 5 | Образование **кокона** (cocoon) → выход молодых червей |

### Значение дождевых червей для почвы

| Функция | Значение |
|---------|----------|
| Обогащение гумусом | Органические вещества |
| Рыхление почвы | Улучшение аэрации и водоснабжения |
| Перемешивание | Улучшение структуры почвы |
| Снижение кислотности | Известковые железы в пищеводе |

## Класс Пьявки (Hirudinea)

| Признак | Характеристика |
|---------|----------------|
| **Целом** | Частично редуцирован (coelom reductum) |
| **Щетинки и параподии** | Отсутствуют |
| **Форма тела** | Сплющена в спинно-брюшном направлении (forma dorsoventralis) |
| **Присоски** | Две — ротовая (acetabulum orale) и задняя (acetabulum posterius) |
| **Пищеварительная система** | Много карманов для запасания крови (могут неделями без пищи) |
| **Слюнные железы** | Содержат **герудин** (hirudin) — антикоагулянт |
| **Размножение** | Половое, гермафродиты, перекрестное оплодотворение |
| **Развитие** | Прямое |

## Ароморфозы кольчатых червей (Annelida)

| № | Ароморфоз (русский) | Ароморфоз (латынь) |
|---|---------------------|---------------------|

## Сравнительная таблица типов червей

| Признак | Плоские черви (Platyhelminthes) | Круглые черви (Nemathelminthes) | Кольчатые черви (Annelida) |
|---------|--------------------------------|--------------------------------|---------------------------|
| **Полость тела** | Отсутствует (паренхима) | Первичная (псевдоцель — pseudocoelom) | Вторичная (целом — coelom) |
| **Пищеварительная система** | Слепо замкнутая | Сквозная (есть анус) | Сквозная (есть анус) |
| **Кровеносная система** | Нет | Нет | **Замкнутая** (clausa) |
| **Выделительная система** | Протонефридии (protonephridia) | Протонефридии (шейные железы) | **Метанефридии** (metanephridia) |
| **Нервная система** | Лестничного типа | Лестничного типа | **Брюшная цепочка** (ganglia ventralis) |
| **Половая система** | Гермафродиты | Раздельнополые (dioeci) | Гермафродиты (Oligochaeta) / раздельнополые (Polychaeta) |
| **Дыхание** | Через покровы / анаэробное | Через покровы / анаэробное | Через покровы / жабры (branchiae) |
| **Членистость (метамерия)** | Нет | Нет | **Есть** (metameria) |
